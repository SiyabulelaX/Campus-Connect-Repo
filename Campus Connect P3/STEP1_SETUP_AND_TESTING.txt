CONFIGURE THE ONLINE SERVICE (NOT YET DONE)
1. Choose an email inbox you control.
2. Create an account at https://formspree.io/ and verify your email.
3. Create TWO forms: Contact and Enquiry. Copy each unique endpoint (format https://formspree.io/f/XXXXXXXX).
4. In contact.html, set data-endpoint="https://formspree.io/f/YOUR_CONTACT_ID" on contactForm.
5. In enquiry.html, set data-endpoint="https://formspree.io/f/YOUR_ENQUIRY_ID" on enquiryForm.
6. Configure notification recipients in Formspree and confirm any verification steps required.
7. Publish/test via an HTTP(S) site. Check your Formspree dashboard and recipient inbox.

MANUAL TEST CASES (MUST BE COMPLETED BY YOU AFTER CONFIGURATION)
[ ] Contact: blank required field is blocked.
[ ] Contact: invalid email is blocked.
[ ] Contact: short message is blocked.
[ ] Enquiry: blank enquiry type is blocked.
[ ] Enquiry: short details are blocked.
[ ] Both: without endpoint, show NOT CONFIGURED (not a false success).
[ ] Both: valid submission reports success ONLY after HTTP success.
[ ] Both: submissions appear in Formspree dashboard / arrive in recipient inbox.
[ ] Both: network error shows failure message and permits retry.
[ ] Check mobile layout and navigation.

NOTE: Client-side validation is for user experience. Formspree handles receipt; configure spam protection and privacy settings before public launch. Do not put private API keys in public HTML.
